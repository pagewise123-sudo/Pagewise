1. Key terms

  • API: the server program your app talks to over the internet.
  • Backend: the server code (API plus background workers).
  • Job queue: a to-do list for slow tasks (OCR, summarizing). The API adds jobs, and separate workers do them, so the app never freezes.
  • Embedding: a list of numbers representing a text's meaning. Similar texts get similar numbers.
  • Vector search (pgvector): finding the texts whose numbers are closest to your question's numbers.
  • RAG (Retrieval-Augmented Generation): find the relevant chunks first, then have the AI answer using only those. This is how "chat with my PDF" works and how we cut hallucinations.
  • Map-reduce summarization: summarize each section (map), then summarize the summaries (reduce). This is how a 500-page book fits into a model with limited memory.
  • OCR: turning pictures of text (scanned pages) into real text.
  • Webhook: a message a service (Stripe, RevenueCat) sends to your server when something happens, such as a payment.

The processing pipeline (the heart of the product)

  1. The app asks the API for a signed URL (a temporary, single-use upload link), then uploads the PDF straight to storage. Your API never carries the big file.
  2. The app tells the API "upload complete", and the API enqueues a job.
  3. Validate: check the real file type (not just .pdf), page count, size, encryption, and quota.
  4. Per-page text check: pages with a text layer are extracted directly, and pages without one go to OCR.
  5. Chunk the text into roughly 500–800 token pieces, each remembering its page range.
  6. Embed the chunks and store them in pgvector.
  7. Map: the AI writes structured notes per section, and every claim must reference chunk IDs.
  8. Reduce: combine the notes into the requested style (short, detailed, flashcards, and so on).
  9. Verification pass: check each cited quote actually appears in its chunk. Unsupported claims are dropped or flagged. This is the main anti-hallucination mechanism.
  10. Status updates (queued → ocr → embedding → summarizing → done/failed) are stored so the app can show progress.

Design rules baked in

  • Swappable providers: the code depends on LLMProvider, EmbeddingProvider, OCRProvider, TTSProvider, and ImageProvider interfaces, and an env variable picks the implementation.
  • Caching: results are keyed by hash (file + settings + prompt version), scoped per user so private documents never leak between accounts. Map notes are reused when you request a second summary style, and provider prompt caching is used where available (verify on the provider's docs).
  • Audio is generated at 1.0× speed and stored. Playback speed is applied on the device, so changing speed never costs another TTS call.
  • Audio is generated per sentence group with known durations. This gives sentence highlighting on any provider, without depending on provider-specific timestamps.

Unit costs I used (assumptions)

  • Summary: an 80-page document (about 32k tokens) costs roughly $0.05–0.15 for AI. A 300-page book costs about $0.35 for the first style, then less for extra styles because notes are reused.
  • Chat: about $0.007 per message on the small model.
  • TTS: 1 hour of speech is about 54,000 characters. At about $4 per million characters (Standard voices), that's about $0.22 per hour. At about $16 per million (Neural), it's about $0.86 per hour. Premium voices such as ElevenLabs can be many times higher.
  • Full-book audio (about 540k characters) costs about $2 (Standard) to $9 (Neural). This is your biggest cost risk, so it must be paid-only and metered.
  • OCR: self-hosted Tesseract has no per-page fee (only CPU). Cloud OCR is roughly $1.50 per 1,000 pages.

8. Safety, privacy, and copyright, designed in from day one

  • Security: short-lived JWTs verified on every request, signed upload URLs, per-user rate limits, strict input validation, secrets only in environment variables, encrypted storage and database at rest (provider features), and no cross-user cache.
  • Privacy: every PDF is private to its owner, users give clear consent before any text goes to an AI provider, and delete and export are real endpoints. We'll also use provider settings that don't train on your data (verify each provider's terms).
  • Copyright: an upload checkbox ("I have the right to use this content"), terms that put responsibility on the user, a takedown contact process, and no sharing of documents between users.
  • Voice licensing: commercial use of TTS depends on your provider plan and each voice's license, especially ElevenLabs library voices. We'll never clone a real person's voice without documented consent. I'll list the exact pages to check in Phase 4.

What I did

I designed the whole system on paper: an Expo app and admin panel talking to a FastAPI backend, with a job queue doing the slow work (OCR, chunking, embeddings, summarizing, audio). Summaries come from a map-reduce pipeline and every claim gets verified against source text, which is how we fight hallucinations. AI, OCR, and TTS sit behind swappable provider interfaces so you control cost. I also produced the data model, the API list, the folder layout, and an honest cost model with a pricing plan.

@app.get("/health")
def health() -> dict[str, str]:
    """Checks that the API can reach the database (with pgvector) and Redis."""
    result: dict[str, str] = {"api": "ok"}

    try:
        with engine.connect() as conn:
            conn.execute(text("SELECT 1"))
            ext = conn.execute(
                text("SELECT extname FROM pg_extension WHERE extname = 'vector'")
            ).scalar()
        result["database"] = "ok"
        result["pgvector"] = "ok" if ext else "missing"
    except Exception as exc:  # noqa: BLE001 - report any failure, don't crash
        result["database"] = f"error: {type(exc).__name__}"

    try:
        redis.Redis.from_url(settings.redis_url).ping()
        result["redis"] = "ok"
    except Exception as exc:  # noqa: BLE001
        result["redis"] = f"error: {type(exc).__name__}"

    return result


@app.get("/health/worker")
def health_worker() -> dict[str, str]:
    """Sends a job to the queue and waits up to 5 seconds for the worker's reply."""
    try:
        reply = ping.delay().get(timeout=5)
        return {"worker": "ok", "reply": reply}
    except Exception as exc:  # noqa: BLE001

import AsyncStorage from "@react-native-async-storage/async-storage";
import { createContext, useContext, useEffect, useState, type ReactNode } from "react";
import { useColorScheme } from "react-native";
import { darkColors, lightColors, type ThemeColors } from "@/src/theme";

export type SchemePref = "light" | "dark" | "system";
const KEY = "app.theme";

interface ThemeValue { pref: SchemePref; resolved: "light" | "dark"; colors: ThemeColors; setPref: (p: SchemePref) => void }

const ThemeContext = createContext<ThemeValue>({ pref: "system", resolved: "light", colors: lightColors, setPref: () => {} });
export const useTheme = () => useContext(ThemeContext);

export function ThemeProvider({ children }: { children: ReactNode }) {
  const system = useColorScheme();
  const [pref, setPrefState] = useState<SchemePref>("system");
  const [loaded, setLoaded] = useState(false);

  useEffect(() => {
    AsyncStorage.getItem(KEY).then((v) => {
      if (v === "light" || v === "dark" || v === "system") setPrefState(v);
      setLoaded(true);
    });
  }, []);

  const setPref = (p: SchemePref) => {
    setPrefState(p);
    AsyncStorage.setItem(KEY, p).catch(() => {});
  };

  const resolved: "light" | "dark" = pref === "system" ? (system === "dark" ? "dark" : "light") : pref;
  const colors = resolved === "dark" ? darkColors : lightColors;

  if (!loaded) return null; // avoid a light->dark flash on launch

  return <ThemeContext.Provider value={{ pref, resolved, colors, setPref }}>{children}</ThemeContext.Provider>;
}

export function PlayerProvider({ children }: { children: ReactNode }) {
  const { session } = useAuth();
  const player = useAudioPlayer(null, { updateInterval: 250 }); // ONE player for the whole app
  const status = useAudioPlayerStatus(player);

  const [trackId, setTrackId] = useState<string | null>(null);
  const [manifest, setManifest] = useState<Manifest | null>(null);
  const [isOffline, setIsOffline] = useState(false);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [rate, setRateState] = useState(1);
  const [sleepChoice, setSleepChoice] = useState<SleepChoice>(null);
  const [deadline, setDeadline] = useState<number | null>(null);
  const loadToken = useRef(0); // ignores a stale response if the user switches tracks quickly

  useEffect(() => {
    setAudioModeAsync({ playsInSilentMode: true, shouldPlayInBackground: true, interruptionMode: "doNotMix" }).catch(() => {});
  }, []);

  useEffect(() => {
    if (!manifest) return;
    player.setActiveForLockScreen(true, { title: manifest.title, artist: "PDF Audio" });
    return () => player.clearLockScreenControls();
  }, [player, manifest?.id]); // eslint-disable-line react-hooks/exhaustive-deps

  const open = useCallback((id: string) => {
    if (id === trackId) return; // already playing this one; tapping it again shouldn't restart it
    const token = ++loadToken.current;
    setTrackId(id);
    setManifest(null);
    setError(null);
    setLoading(true);
    setRateState(1);
    setSleepChoice(null);
    setDeadline(null);

    (async () => {
      const offline = await getOffline(id).catch(() => null);
      if (loadToken.current !== token) return;
      if (offline) {
        setManifest(offline.manifest);
        setIsOffline(true);
        player.replace({ uri: offline.uri });
        player.play();
        setLoading(false);
        return;
      }
      try {
        const m = await apiAudio.track(id);
        if (loadToken.current !== token) return;
        if (m.status !== "done" || !m.url) throw new Error("not ready");
        setManifest(m);
        setIsOffline(false);
        player.replace({ uri: m.url });
        player.play();
      } catch {
        if (loadToken.current === token) setError("error");
      } finally {
        if (loadToken.current === token) setLoading(false);
      }
    })();
  }, [trackId, player]);

  const close = useCallback(() => {
    loadToken.current++;
    player.pause();
    setTrackId(null);
    setManifest(null);
    setError(null);
  }, [player]);

  const toggle = useCallback(() => {
    if (status.playing) { player.pause(); return; }
    if (status.duration > 0 && status.currentTime >= status.duration - 0.2) player.seekTo(0);
    player.play();
  }, [player, status.playing, status.duration, status.currentTime]);

  const seek = useCallback((seconds: number) => {
    const dur = status.duration || manifest?.total_seconds || 0;
    player.seekTo(Math.max(0, Math.min(dur, seconds)));
  }, [player, status.duration, manifest?.total_seconds]);

  const setRate = useCallback((r: number) => { setRateState(r); player.setPlaybackRate(r); }, [player]);
  const setSleep = useCallback((c: SleepChoice) => {
    setSleepChoice(c);
    setDeadline(typeof c === "number" ? Date.now() + c * 60_000 : null);
  }, []);

  const stopForSleep = useCallback(() => { player.pause(); setDeadline(null); setSleepChoice(null); }, [player]);
  useEffect(() => {
    if (deadline === null) return;
    const id = setTimeout(stopForSleep, Math.max(0, deadline - Date.now()));
    return () => clearTimeout(id);
  }, [deadline, stopForSleep]);
  useEffect(() => {
    if (deadline !== null && Date.now() >= deadline) stopForSleep();
  }, [status.currentTime, deadline, stopForSleep]);
  useEffect(() => {
    if (status.didJustFinish) { setDeadline(null); setSleepChoice(null); }
  }, [status.didJustFinish]);

  // Privacy: stop and forget everything if the signed-in user changes.
  const uid = session?.user.id ?? null;
  const lastUid = useRef(uid);
  useEffect(() => {
    if (lastUid.current !== uid) close();
    lastUid.current = uid;
  }, [uid]); // eslint-disable-line react-hooks/exhaustive-deps

  const sleepRemainingMin = deadline === null ? null : Math.max(1, Math.ceil((deadline - Date.now()) / 60000));

  const value = useMemo<PlayerValue>(() => ({
    trackId, manifest, isOffline, loading, error, player, status, rate, sleepChoice, sleepRemainingMin,
    open, close, toggle, seek, setRate, setSleep,
  }), [trackId, manifest, isOffline, loading, error, player, status, rate, sleepChoice, sleepRemainingMin, open, close, toggle, seek, setRate, setSleep]);

  return <PlayerContext.Provider value={value}>{children}</PlayerContext.Provider>;
}

import arAudio from "./ar.audio.json";
import arBilling from "./ar.billing.json";
import arExtra from "./ar.extra.json";
import arMore from "./ar.more.json";
import arRelease from "./ar.release.json";
import arSixc from "./ar.sixc.json";
import en from "./en.json";
import enAudio from "./en.audio.json";
import enBilling from "./en.billing.json";
import enExtra from "./en.extra.json";
import enMore from "./en.more.json";
import enRelease from "./en.release.json";
import enSixc from "./en.sixc.json";

export type Lang = "en" | "ar";
const KEY = "app.language";

function applyDirection(lang: Lang): boolean {
  const rtl = lang === "ar";
  if (Platform.OS === "web") {
    document.documentElement.dir = rtl ? "rtl" : "ltr";
    document.documentElement.lang = lang;
    return false;
  }
  I18nManager.allowRTL(true);
  if (I18nManager.isRTL !== rtl) {
    I18nManager.forceRTL(rtl);
    return true;
  }
  return false;
}

export async function initI18n(): Promise<void> {
  const stored = (await AsyncStorage.getItem(KEY)) as Lang | null;
  const device = Localization.getLocales()[0]?.languageCode;
  const lang: Lang = stored ?? (device === "ar" ? "ar" : "en");
  applyDirection(lang);
  await i18n.use(initReactI18next).init({
    resources: {
      en: { translation: { ...en, ...enExtra, ...enAudio, ...enBilling, ...enMore, ...enRelease, ...enSixc } },
      ar: { translation: { ...ar, ...arExtra, ...arAudio, ...arBilling, ...arMore, ...arRelease, ...arSixc } },
    },
    lng: lang,
    fallbackLng: "en",
    interpolation: { escapeValue: false },
  });
}

export async function setLanguage(lang: Lang): Promise<boolean> {
  await AsyncStorage.setItem(KEY, lang);
  await i18n.changeLanguage(lang);
  return applyDirection(lang);
}

9. What you learned

Why one player instance. A mini-player is only possible if playback state lives above any single screen. Instead of creating a new player per screen (Phase 4's approach), PlayerContext creates one player when the app starts and calls .replace() on it whenever a different track is opened — the same trick already used for voice previews in Phase 4. Position and rate carry over naturally across navigation because it's the same object.

Why theme-aware components pay off first. Converting Button, Card, Chip, and friends to read useTheme() internally means every screen that already uses them gets dark-mode coverage for free, with zero changes to that screen. Only screens with their own raw colored Views or StyleSheet.create blocks need the extra three-line treatment.

Known gaps

  • The mini-player's bottom offset on tab screens is an approximation, not measured from the real tab bar.
  • No haptic feedback, no swipe-to-dismiss, no queue (only one track at a time, which matches the product's design).
